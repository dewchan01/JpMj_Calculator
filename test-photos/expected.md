# Expected tiles

Place your test photos in this folder. Add one entry per photo with the correct tiles.

Notation: `m` = characters, `p` = circles, `s` = bamboo, `z` = honors.
Use `0m`, `0p`, or `0s` for red fives.
Honors: `1z` East, `2z` South, `3z` West, `4z` North, `5z` White, `6z` Green, `7z` Red.

Example (replace with your actual photo and tiles):

```text
hand-01.jpg: 123m456m789p234s55p
```

For photos containing melds, list concealed tiles and each meld separately. Note any rotated,
obscured or face-down tiles so we can distinguish detection errors from invisible information.
