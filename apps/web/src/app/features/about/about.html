{{ 'Transparent by design.' | t }}

{{ 'Independent scoring with selectable Mahjong Soul, Tenhou and Custom rules.' | t }}

{{ 'What works' | t }}

{{ 'Manual 3P/4P scoring includes standard Yaku, all standard Yakuman and special waits, first-turn claims, Pao, multiple Ron, draws and Nagashi Mangan. Rule presets control the differences; settlements update dealer, honba and match state automatically.' | t }}

{{ 'What needs your input' | t }}

{{ 'The winning tile is included in the concealed hand. Declare the winner, discarder, dealer, round wind and situational claims yourself. The scorer validates tile structure and claim consistency; it cannot establish Furiten, legal Riichi timing or unrecorded game history.' | t }}

{{ 'Explicit limits' | t }}

{{ 'You must declare legal timing, Tenpai, Nagashi eligibility, call order and revealed indicators. The app checks consistency and calculates settlement, but has no full wall/discard simulation. Local Yaku, chombo penalties, final Uma/Oka and rank progression are outside these presets.' | t }}

{{ 'The North-bisection option is a house-rule alternative that splits the absent payer’s base share before rounding. It is not the ranked default. Ranked presets use Tsumo-loss and disable Kiriage.' | t }}

{{ 'Photos and privacy' | t }}

{{ 'Photo recognition uploads selected images to a configurable API endpoint. Mock mode stays local. Review suggestions before adding tiles; manual entry always works. Photos are not saved with matches.' | t }}

{{ 'Installing the app' | t }}

{{ 'On the home page, the install popup explains how to add this app to your device. Use Install app when available, your browser menu, or Share → Add to Home Screen on iPhone and iPad.' | t }}

{{ 'Next time dismisses the popup for this visit; it returns when you reload or visit the home page again. Escape has the same effect. Close saves your choice so the popup stays hidden in this browser. The popup is also hidden when you open the installed app.' | t }}

{{ 'Photo recognition requires internet access. Manual tile entry works offline.' | t }}

{{ 'Local data' | t }}

{{ 'Matches and manual drafts are stored in IndexedDB. Clearing site data removes them. Export a match from its history for a backup. An installed production PWA can work offline after its first successful online load. HTTPS is required away from localhost.' | t }}

{{ 'History' | t }}

{{ 'Every settlement stores its rules, inputs, payments and previous/next round state. Riichi deposits fund escrow before it is awarded. Undo restores the latest event’s transfers and round progression; older edits remain blocked.' | t }}
