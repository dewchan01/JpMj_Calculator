# Mahjong Soul background music

Selected from the user-requested [soundboard](https://www.101soundboards.com/boards/1128963-mahjong-soul-jantama-que-hun-video-game-music). The soundboard blocked direct downloads, so the matching named assets were downloaded from the public Mahjong Soul game asset manifest (version 0.11.252.w) on 2026-10-30.

Only the six requested lobby tracks, Game / Game Master / 23ex Duiju1-4, and the nine listed Liqi tracks plus Yichujifa are included. No other music or effect tracks are used.

Rights remain with Cat Food Studio / Yostar and the respective rights holders. Public availability does not grant an open redistribution license.
